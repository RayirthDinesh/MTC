01 · Design system

Navy, gold, springs.

Lighthouse at night. Gold is the only loud color. Apple-style physical motion: springs, not eases; transform and opacity only; every press scales; reduced-motion respected.

Motion spec (Framer Motion)

spring.ui    = { type:"spring", stiffness:380, damping:32 }   // buttons, toggles
spring.sheet = { type:"spring", stiffness:260, damping:30 }   // modals, level-up
spring.pop   = { type:"spring", stiffness:500, damping:18 }   // stamps, badges
page: fade + y:12 → 0 + blur 6px → 0 (AnimatePresence, mode="wait")
lists: stagger 0.04s · numbers: count-up 800ms · map pulse: ring scale 1→3, opacity .6→0, 1.6s
tab underline: layoutId shared element · reduced-motion: opacity only

03 · Shared contract (merge first)

Freeze this before branching.

Both people code against the same store API. Stub it on main first so branches never touch each other's files.

src/store.js     getState() · subscribe(fn) · reset()           // persists + window 'storage' sync
                 actions: signUp(user) login(id) logout()
                          checkIn(userId, code)  → {ok, stamp, levelUp}
                          connect(a,b)  sendMessage(from,to,text)
                          createEvent(ev)  inviteCoHost(eventId, campusId)
                          linkCampuses(a,b)  logActivity(type,campusId)
                 selectors: visibleUsers(viewer)  ← ONLY place gender filter lives
                            sameGender(a,b) · levelOf(stamps) · strength(campusId)

04 · Branch split

Five branches, two people.

Each branch owns its own files. Shared files (store.js, seed.js, App.jsx routes, theme.css) are frozen after feat/foundation; need a change? tiny PR to main, both rebase.

Git rules

git checkout main && git pull
git checkout -b feat/<name>        # one branch per row above
# commit small, push often
git fetch && git rebase origin/main  # before every PR
# PR → merge in this order: foundation → landing-signup + student-passport + admin-map → connect-chat → campus-events → polish
# never edit another branch's files; shared files = PR to main first
